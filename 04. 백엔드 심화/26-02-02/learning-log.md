### DB에서 제약조건

DB에서 제약조건이란, 데이터의 정합성을 유지하기 위한 규칙을 의미한다. 

DEFAULT: 기본값
    - 테이블 생성 시, 컬럼에 기본값을 설정할 수 있다.
    - INSERT 문에서 해당 컬럼의 값을 생략할 경우, 기본값이 사용된다.
AUTO_INCREMENT: 자동증가
    - 테이블 생성 시, 컬럼에 자동증가를 설정할 수 있다.
    - INSERT 문에서 해당 컬럼의 값을 생략할 경우, 자동증가가 적용된다.
NOT NULL: NULL 허용하지 않음
    - 테이블 생성 시, 컬럼에 NULL 허용하지 않음을 설정할 수 있다.
    - INSERT 문에서 해당 컬럼의 값을 생략할 경우, NULL이 저장되지 않는다.
UNIQUE: 유일한 값
    - 테이블 생성 시, 컬럼에 유일한 값을 설정할 수 있다.
    - INSERT 문에서 해당 컬럼의 값을 중복할 경우, 오류가 발생한다.
PRIMARY KEY: 기본키
    - 테이블 생성 시, 컬럼에 기본키를 설정할 수 있다.
    - INSERT 문에서 해당 컬럼의 값을 중복할 경우, 오류가 발생한다.
FOREIGN KEY: 외래키
    - 테이블 생성 시, 컬럼에 외래키를 설정할 수 있다.
    - INSERT 문에서 해당 컬럼의 값을 중복할 경우, 오류가 발생한다.
ON DELETE: 삭제
    - 테이블 생성 시, 컬럼에 삭제를 설정할 수 있다.
    - INSERT 문에서 해당 컬럼의 값을 중복할 경우, 오류가 발생한다.
ON UPDATE: 수정
    - 테이블 생성 시, 컬럼에 수정을 설정할 수 있다.
    - INSERT 문에서 해당 컬럼의 값을 중복할 경우, 오류가 발생한다.


### MySQL(mariaDB) 날짜 / 시간 타입

1. DATE: 날짜만 포함(YYYY-MM-DD)
2. DATETIME: 날짜와 시간을 포함(YYYY-MM-DD HH:MM:SS)
3. TIME: 시간만 포함(HH:MM:SS)
4. TIMESTAMP: 시스템 시간대 정보에 맞게 일시를 저장(YYYY-MM-DD HH:MM:SS 24시간제)
    - 자동입력 가능!
    - UTC 시간대를 기준으로 저장됨 (한국시간 - 9시간)
