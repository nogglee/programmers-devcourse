### ✅ Commit Convention

#### 1. 커밋 메시지 형식
`Type: 요약 메시지 (날짜)`

#### 2. 커밋 타입 상세
| Type | 설명 | 해당 파일 예시 |
| :--- | :--- | :--- |
| **docs** | 학습 이론 정리 및 문서 수정 | `learning-log.md`, `README.md` |
| **feat** | 새로운 실습 코드 및 예제 파일 추가 | `example.html`, `example.js` 등 코드/텍스트 실습 |
| **fix** | 잘못된 내용 수정 및 오타 정정 | 학습 내용 중 틀린 정보나 오타 수정 시 |
| **refactor** | 파일 위치 이동 및 폴더 구조 변경 | 폴더 경로 변경, 파일명 변경 (내용 수정 없음) |
