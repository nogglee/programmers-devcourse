## 학습내용

### 01. 웹 기본 개념

> **Internet:**  
> International + Network 의 약자. 우리는 모두 연결 되어있다는 의미  

> **Web:**  
> Word Wide Web 의 준말. 인터넷에 연결된 컴퓨터를 통해 정보 공유를 할 수 있는 공간을 의미  


Web은 스위스의 컴퓨터 과학자 팀 버너스리에 의해 만들어졌다.  
유럽 입자 물리 연구소(CERN)에서 같이 일하는 동료 연구원들과 정보교환을 빠르게 하기 위해 고안되었다고 한다.  

---

### 02. 웹의 구조

식당에서 음식을 ‘서빙’하는 자를 우리는 ‘서버’, 주문한 음식을 받는 자는 ‘클라이언트’라고 부른다.  
웹에서도 같은 개념으로 제공하는 컴퓨터를 ‘Server’, 서비스를 요청/이용하는 컴퓨터를 ‘Client’라고 부른다.  

Server와 Client간 정보를 주고 받을 때 지켜야하는 ‘약속’ 같은 통신 규격이 존재하는데, 이것을 ‘프로토콜’이라 부른다.  
서로가 Internet으로 연결되어있다면, 이때 적용되는 규격은 웹 프로토콜인, HTTP(HyperText Transfer Protocol)을 사용한다.  

웹 서비스는 필요에 따라 Server와 Client를 모두 개발해야하며, 개발자는 크게 2가지 파트로 분류할 수 있다.  
- 프론트엔드: GUI를 제공하여 사용자와 웹사이트간의 상호작용(글자 입력, 버튼 클릭 등)을 구현
- 백엔드: 프론트엔드에서 전달 받은 데이터와 요청을 내부 데이터와 연산을 활용하여 처리하고 프론트엔드에 결과를 전달

---

### 03. 프론트엔드

프론트엔드 구현을 위해 필요한 3요소는 HTML, CSS, Javascript 3가지이다.  
- HTML: 웹 페이지 구성 요소들의 구조
- CSS: 웹 페이지 구성 요소들을 꾸밈
- Javascript: 웹 페이지 구성 요소들의 동적 작동 구현

위 도구를 활용하여 웹 서비스 개발 작업을 할 수 있는 공간 역할을 하는 툴을 IDE(통합 개발 환경)라 한다.  
대표적으로 사용되는 IDE 종류로는 VSCode, eclipse, intellij 가 있다.

단순히 텍스트만 나열된 것이 아닌, hyperText를 따라 페이지를 이동할 수 있도록 정보를 제공한다.  
HTML의 풀 명칭인 HyperText Markup Language 에서도 hyperText가 언급됨을 알 수 있다.  

hyperText에 걸린 link를 타고 웹 페이지로 이동 하는 것을 ‘웹 서핑’ 또는 ‘웹 브라우징’ 한다라고 표현 할 수 있다.  
우리가 웹 브라우징을 할 수 있는 공간인 chrome, safari 등을 ‘웹 브라우저’라고 칭한다.  

> **HyperText:**  
> 책은 보통 앞에서 뒤로 읽지만, ‘웹 문서’는 글 속에 있는 링크를 클릭하면 순서와 관계 없이 원하는 정보를 제공하는 페이지로 이동한다. 이렇게 단순히 글을 ‘읽는 공간’이 아닌, 정보를 ‘탐색하는 공간’이 되게 만든 핵심원리가 바로 HyperText이다. 
>
> ‘Hyper’는 그리스어에서 온 말로, `over:위에` `beyond:넘어` `excess:초과하여` 라는 뜻이다. 그래서 ‘hyper-’가 앞에 붙는 단어는 **기존 범위를 넘어선 상태** 라는 의미를 강화해 준다.

위 내용에서 알 수 있듯, 정적으로 텍스트를 읽어나가는 것이 아니라 정보를 탐색을 하는 공간이 web이고,  
그런 web은 hyperText로 이루어져 있으며, hyperText에 걸린 link를 타고 webPage를 넘나드는 것을  

HTML을 구성할 땐 `< >` 괄호를 사용하는데, ‘태그’라는 명칭을 사용한다.  
이러한 태그는 여러 종류가 있으며, 웹 페이지의 구성 요소마다 태그안에 작성되는 텍스트가 달라진다.
