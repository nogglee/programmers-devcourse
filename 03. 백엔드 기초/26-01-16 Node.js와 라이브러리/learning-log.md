### 01. method

HTTP 템플릿에는 '목적'을 담아서 통신하는데, 이를 'method'라고 한다.
method 사용 시 규약에 맞추어 사용해야 한다.

**규약**
- `POST` : 생성(등록)
- `GET` : 조회
- `PUT` / `PATCH` : 덮어쓰기 / 부분 수정
- `DELETE` : 삭제
- `HEAD` : 메타데이터 조회
- `OPTIONS` : 서버가 지원하는 메서드 목록 조회
- `TRACE` : 요청이 프록시를 통과하는 경로 확인
- `CONNECT` : 터널링을 위한 연결 요청

### 02. Node.js 특징

싱글 스레드, 이벤트 기반, 논 블로킹 I/O 이라는 특징을 가지고있다.  
위 특징들을 '슈의 라면가게' 게임에 빗대어 설명해보면,  

싱글 스레드:  
슈의 라면가게는 슈 혼자 운영한다.  
게임의 마감 시간이 임박할수록 손님은 계속 몰려오고, 슈 혼자 어떻게든 주문을 쳐내야한다.  

논 블로킹 I/O:  
게임에서 득점하려면 고객이 2명 이상 방문했을 때, 라면 1개가 온전히 완성될 때까지 기다리지 않는다.  
라면 1개를 끓이는 데 20초가 걸린다고 가정했을 때, 라면을 끓이는 동안 다른 손님의 주문을 계속 받아야한다.  

이벤트 기반:  
고객이 없는데 라면을 끓이면 오버쿠킹이 되어 라면이 타버린다.  
고객이 오는 순간 주문을 받아서 라면을 끓이기 시작한다.  
이렇게 이벤트가 있으면 처리하고 없으면 기다리는 특성이 이벤트 기반이다.

### 04. 콜백 함수

> **콜백 함수:**  
> 함수의 매개변수로 변수 또는 값을 전달하는 것이 아니라, '함수 자체를 전달'하는 것을 의미한다.  

아래 code는 figlet 라이브러리 사용 예시이다.

```javascript
figlet
(
    'Hello NOGGLEE!!', function(err, data) 
    {
        if (err) 
        {
            console.log('Something went wrong...');
            console.dir(err);
            return;
        }
        console.log(data);
    }
);
```
figlet 함수는 두 개의 인자를 받는다.  

```javascript
figlet({출력할 문자열}, {콜백 함수})
```

1. figlet 함수는 첫 번째 인자인 문자열을 비동기적으로 처리한다.
2. 문자열을 아스키 아트로 변환하는 작업이 완료되면,
   두 번째 인자로 전달한 콜백 함수를 실행한다.
   1. 이 콜백 함수는 작업 완료 시점에 실행되므로, 비동기 처리의 결과를 다루는 역할을 한다.
   2. 해당 함수는 이 위치에서만 사용되는 일회성 로직이므로 익명 함수로 작성하였다.
      (별도의 이름을 붙여 재사용할 필요가 없기 때문이다.)

콜백 함수 자체가 곧 비동기 처리를 의미하는 것은 아니다.  

> **비동기 처리**  
> 비동기 처리란, 어떤 작업이 즉시 끝나지 않고 나중에 완료되며,  
> 그 완료 시점에 실행할 로직을 함수 형태로 전달하는 구조를 말한다.  

figlet 예제에서는 문자열을 아스키 아트로 변환하는 데 시간이 걸릴 수 있기 때문에,  
figlet 함수는 작업을 바로 반환하지 않고,  
작업이 끝났을 때 실행할 콜백 함수를 인자로 받는다.  

아래 함수는 server를 생성하는 예시이다.  

```javascript
function onRequest(request, response) 
{
    response.writeHead(200, {'Content-Type': 'text/plain'});
    response.write('Hello Node.js');
    response.end();
}

http.createServer(onRequest).listen(8080);
```

http 모듈의 createServer 함수는 요청이 들어올 때마다 실행할 함수를 인자로 받는다.
여기서 onRequest 함수는 서버에 HTTP 요청이 도착했을 때 호출되는 콜백 함수이며,
요청(request)과 응답(response)을 처리하는 역할을 한다.
